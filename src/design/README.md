# Generated design tokens

These files are Signal's tokens, generated by [YouIyouX](https://github.com/ap9000/youiyoux) (`youi`) from the design-language repo [ap9000/toolroll-design](https://github.com/ap9000/toolroll-design). Do not edit them here: change the tokens there and regenerate.

| File | Used by |
| --- | --- |
| `tokens.css` | Every `--so-*` variable, light and dark (device scheme and a pinned `data-theme`). The server prepends it to `src/server/console.css` (`STYLE` in `src/server/chrome.ts`), so every page, including the React workspace, gets one copy. |

Provenance of the current files:

- Signal 1.0.0, toolroll-design `9e35768563af63d876e6377e6b0b74fc0399e297`
- youi from youiyoux `ad046678ce5feae04046e792b7b5d14d38cca88f`

To regenerate, from a toolroll-design checkout with youiyoux installed (see its README), sync into a scratch copy of Toolroll and copy only the token outputs back:

```sh
youi sync --design . --project <toolroll copy> --config pilot/toolroll/youi.project.json
cp <toolroll copy>/src/design/tokens.css src/design/
youi parity --design . --prefix so --css <served stylesheet>
```
